## دور 1 — مواردی که اجرای فنی به آن‌ها وابسته است

### Q09 — روش نهایی ورود چیست؟

- [x] ✅ **شمارهٔ موبایل + رمز یک‌بارمصرف پیامکی** ☆ — شمارهٔ تلفن شناسهٔ حساب است؛ ساده‌ترین روش برای بازار ایران
- [ ] رمز یک‌بارمصرف موبایل، با امکان افزودن ایمیل در آینده — تلفن روش اصلی است؛ ایمیل را می‌توان بعداً افزود و برای ورود دوم تأیید کرد
- [ ] فقط ایمیل + گذرواژه — بدون وابستگی به پیامک؛ تناسب کمتر با کاربران محلی
- [ ] هر دو به‌عنوان روش‌های هم‌ارز — برای جلوگیری از ایجاد دو کیف پول، به اتصال امن حساب‌ها نیاز دارد

### Q36 — خروجی‌های استودیو چگونه قیمت‌گذاری می‌شوند؟

- [ ] قیمت ثابت برای هر نوع خروجی ☆ — یک قیمت جداگانه برای تصویر، ویدیو و تغییر رنگ؛ ساختار داده و تجربهٔ کاربری ساده
- [ ] قیمت‌گذاری بر اساس استایل — هر استایل هزینهٔ توکنی خودش را دارد
- [x] ✅ **قیمت پایهٔ ثابت + هزینهٔ اضافهٔ استایل** — قیمت پایه بر اساس نوع خروجی، به‌اضافهٔ هزینهٔ اختیاری برای استایل‌های ویژه

### Q33 — اگر هنگام Create کارتی تصویر محصول نداشته باشد، چه می‌شود؟

- [x] ✅ **جلوگیری از ادامه تا تکمیل یا حذف کارت** ☆ — Create غیرفعال می‌شود و کارت‌های خالی مشخص می‌شوند

- [ ] حذف خودکار کارت‌های خالی — پس از تأیید حذف می‌شوند و خلاصه‌ای از موارد کنارگذاشته‌شده نمایش داده می‌شود
